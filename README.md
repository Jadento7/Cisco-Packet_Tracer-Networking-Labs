# Cisco Packet Tracer Networking Labs

This repository contains Cisco Packet Tracer labs focused on networking fundamentals, routing, switching, IP addressing, VLANs, and troubleshooting.

Each lab includes a written README, screenshots, configuration steps, verification results, and key takeaways.

## Labs

| Lab | Topic | Skills Practiced |
|---|---|---|
| 01 | Static Routing | IP addressing, router interfaces, static routes, ping testing |
| 02 | Basic Switching | Switch connections, end-device communication, basic LAN setup |
| 03 | VLANs | VLAN creation, access ports, network segmentation |
| 04 | Inter-VLAN Routing | Router-on-a-stick, trunking, gateway configuration |

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 Addressing
- Static Routing
- Switching Concepts
- Network Troubleshooting

## Purpose

The purpose of this repository is to document hands-on networking labs and demonstrate practical understanding of core networking concepts.

## Security and Ethics Notice

All labs were completed in Cisco Packet Tracer using simulated devices. No real systems, public networks, or unauthorized devices were accessed.
